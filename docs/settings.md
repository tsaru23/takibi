# 設定パネルの設計メモ

設定パネルの区分と並び、それぞれの方針、項目の一覧をまとめます。実装は `index.html` の設定パネル（HTML、CSS、`SLIDERS` と `ENV` の定義、UI のイベント処理）にあります。

## 区分と並び

項目が増えるたびに足していくと、並びに筋がなくなります。そこで、よく使う順に、「何を変えるか」で5つの区分に分けました。

| 順 | 区分 | 何を変えるか |
|---|---|---|
| 1 | シーン | 場所と季節、それに合わせた演出 |
| 2 | 焚火 | 火そのものの燃え方 |
| 3 | 音 | 音量、音の聞き方、環境音 |
| 4 | 映像 | 見た目の負荷と見え方 |
| 5 | その他 | 端末まわりの設定と、初期化 |

- デスクトップのパネルとスマホのボトムシートで、区分も並びも同じです。
- スマホでは区分ごとのアコーディオンにします。初期は「シーン」と「焚火」だけが開いています。開閉は `takibi.ui.v1` に覚えます。
- 各区分の見出しの横に、閉じていても状態が分かる短い要約を出します。

| 区分 | 要約の例 |
|---|---|
| シーン | 池・秋 |
| 焚火 | 自動くべ・×1.0 |
| 音 | 音量70%・ヘッドホン・環境音2 |
| 映像 | 草ふつう（映像オフのときは「映像オフ（音だけ）」） |
| その他 | 画面つけたまま（オンのときだけ） |

## 方針

- **ラベルは短く、補足は下に小さく。** 「燃焼音（ゴー）の音量」は「燃える音」にして、補足に「ゴーという低い音の大きさ」と書きます。
- **同じ種類の部品は、見た目と並びをそろえる。** オン・オフはすべて、ラベルが左でスイッチが右です。スライダーは、ラベルが左で値が右、その下につまみです。選択肢はセグメントです。
- **環境音は、いまオンのものを上に出す。** オフのものは、畳める「ほかの環境音（件数）」にまとめます。オンのものが1つもないときは、見出しが「すべての環境音（件数）」になります。「ほかの環境音」の開閉は `takibi.ui.v1` の `envMore` に覚えます。
- **シーンで自動でオンになった音には、「シーンの音」の印を付ける。** 自動オンの指定は `scenes/*.js` の `audio.autoOn` です。手でスイッチを触ると、印は消えます。
- **季節の音は、その季節だけの項目を別に出す。** 見出しは「季節の音（秋）」のように季節名が付きます。
- **冬の虫と蛙は、グレーアウトして「冬は〜が鳴きません」と説明する。** これまでと同じです。
- **「音の聞き方」は音の区分の、全体の音量の下に置く。** 切り替えると、`window.TAKIBI.setAudioOutput(S.audioOut)` を呼びます。この関数が無くても、設定は保存されます。起動時の反映は、音の側が `S.audioOut` を読んで行います。
- **「設定を初期値に戻す」は、確認のダイアログを出してから行う。** `takibi.settings.v1` を消して、読み込み直します。消えるのは設定だけで、パネルの開閉（`takibi.ui.v1`）は残ります。読み込み直しの間は、設定を保存し直さないようにしています。
- **既存の保存キーは変えない。** 変えると、使っている人の設定が消えるためです。新しい項目だけ、新しいキーにします。

## 項目の一覧

保存先は、特に書いていなければ `localStorage` の `takibi.settings.v1`（JSON 1つ）です。表の「保存キー」は、その中のプロパティ名です。

### 1. シーン

| 項目 | 部品 | 保存キー | 初期値 |
|---|---|---|---|
| シーン | セレクト | `scene` | `forest`（季節の木） |
| 季節 | セグメント（春・夏・秋・冬） | `season` | 今日の月から決まる季節 |
| 季節の演出 | スイッチ | `seasonFx` | オン |
| ホタル | スイッチ | `fireflies`、`firefliesManual` | 夏だけオン（手で変えたら、その値） |
| 夜空（星・月・流れ星） | スイッチ | `nightSky` | オン |

### 2. 焚火

| 項目 | 部品 | 保存キー | 初期値 |
|---|---|---|---|
| 自動くべ | スイッチ | `autoFeed` | オン |
| 燃える速さ | スライダー（×0.2〜3） | `speed` | ×1.00 |
| パチパチの頻度 | スライダー | `crackFreq` | 50% |
| パチパチの大きさ | スライダー | `crackSize` | 50% |
| 燃える音 | スライダー | `roar` | 50% |

### 3. 音

| 項目 | 部品 | 保存キー | 初期値 |
|---|---|---|---|
| 全体の音量 | スライダー | `master` | 70% |
| 音の聞き方（新設） | セグメント（イヤホン・ヘッドホン／スピーカー／モノラル） | `audioOut`（`headphones`、`speakers`、`mono`） | `headphones` |

環境音は、1項目につきスイッチ（`on_<id>`、初期値はオフ）と音量（`vol_<id>`、初期値70%）があります。

| 置き場所 | 項目（id） |
|---|---|
| 環境音 | さざ波（`wave`）、虫の声（`insect`）、蛙の声（`frog`）、雨（`rain`）、風（`wind`）、竹のささやき（`bamboo`）、フクロウ（`owl`）、川の流れ（`river`）、洞窟の風（`cavewind`） |
| 季節の音 | 春: せせらぎ（`brook`）。夏: 風鈴（`chime`）、遠くの花火（`fw`）。秋: 落ち葉のカサカサ（`leaves`）。冬: やかんのしゅんしゅん（`kettle`）、雪の静けさ（`snowq`、音量なし） |
| 末尾に単独 | シーンの効果音（`scenesfx`） |

シーンの自動オンで入った音は、次回起動のときに「元の状態」が分からなくなるため、`on_<id>` には保存しません（これまでと同じです）。

### 4. 映像

| 項目 | 部品 | 保存キー | 初期値 |
|---|---|---|---|
| 明るさ | スライダー（30〜160%） | `brightness` | 100% |
| 草の量 | セグメント（多い・ふつう・少ない・なし） | `grass`、`grassAuto` | `normal`（初めてスマホで開いたときは `few`） |
| ゆっくり見回す | スイッチ | `lookAround` | オフ |
| 1周の速さ | セグメント（ゆっくり・ふつう・はやめ）。見回すがオンのときだけ表示 | `lookSpeed` | `normal` |
| 映像オフ（音だけ） | スイッチ | `videoOff` | オフ |

`grassAuto` は、重いときに自動で草を減らした分で、画面には出ません。

### 5. その他

| 項目 | 部品 | 保存キー | 初期値 |
|---|---|---|---|
| 画面をつけたままにする（対応端末のみ） | スイッチ | `keepAwake` | オフ |
| 設定を初期値に戻す（新設） | ボタン | なし | なし |

## 変更前との対応

| 変更前の区分 | 変更前のラベル | 変更後 |
|---|---|---|
| シーンと季節 | シーン、季節、季節の演出、ホタル、夜空（星・月・流れ星） | シーン（夜空の補足は「星・月・流れ星」） |
| 焚火 | 草の量 | 映像 |
| 焚火 | 明るさ | 映像 |
| 焚火 | パチパチの頻度、パチパチの大きさ、燃焼音（ゴー）の音量、燃える速さ | 焚火（「燃焼音（ゴー）の音量」は「燃える音」） |
| 焚火 | 全体音量 | 音（「全体の音量」） |
| 焚火 | 自動くべ（薪が減ったら足す） | 焚火（補足に移動） |
| 焚火 | 映像オフ、ゆっくり見回す、1周の速さ | 映像 |
| 焚火 | 画面をつけたままにする | その他 |
| 環境音 | 16項目すべて | 音（環境音、季節の音、シーンの効果音に振り分け） |
